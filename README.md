# Clinical Evidence QA

Clinicians and researchers ask clinical questions (treatment options, drug interactions, outcomes) and get answers with
inline citations to PubMed abstracts and open-access full text. When the evidence is weak, it says so instead of
guessing. Scope v1 to one clinical area, such as type 2 diabetes treatments or anticoagulation, so the corpus and eval
set stay manageable.

Clinical evidence Q&amp;A over PubMed and PMC with inline citations and abstention when evidence is weak. Hybrid
retrieval, cross-encoder reranking and an eval-gated CI pipeline measuring faithfulness, citation accuracy and
hallucination rate.
